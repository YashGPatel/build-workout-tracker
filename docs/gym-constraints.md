# Gym constraints

Physical facts about the gym that any new programme has to respect. Update
this file when the gym changes, and re-read it before writing a new plan.

## Layout — five rooms

| Room | Equipment |
|---|---|
| **Cable room** | All cable machines, lat pulldown. Also a single pair of dumbbells up to 10kg. |
| **Dumbbell section** | Dumbbells, EZ bars, flat and incline benches. |
| **Barbell section** | Olympic bars, adjustable racks. No benches. Adjacent to the DB section — dumbbells can be carried here for standing work. |
| **Machine room** | Shoulder press, dip machine, leg extension, leg curl, rear delt machine. |
| **Preacher room** | Preacher pad only, no bench. Adjacent to the DB section. |

## The superset rule

> **Both exercises in a superset must be doable without leaving your station.**

In practice that means one of:

1. **Same station, same attachment** — e.g. rope pushdown ↔ rope hammer curl:
   clip the rope once, change the pulley height between exercises.
2. **Same station, same bench** — e.g. seated DB press ↔ incline DB curl:
   one bench, two angles.
3. **Station plus portable equipment** — e.g. lat pulldown ↔ DB lateral raise:
   carry the dumbbells to the pulldown station.

Pairings that break the rule:

- Two different machines (lat pulldown + a separate cable station)
- One station but an attachment swap every round (handle ↔ rope)
- Two rooms (preacher pad + DB bench)

## Increments

| Equipment | Steps |
|---|---|
| Dumbbells | 1kg to 10kg, then 2kg (10, 12, 14…) |
| Cable stacks | 5kg, plus **one** hangable plate (1.25 or 2.5kg) |
| Loadable EZ bar | 9kg empty; smallest plate 1.25kg → 2.5kg steps |
| Fixed EZ bars | 10kg to 40kg in 5kg steps — too coarse for light work |
| Plates | 1.25kg smallest |

**Cables can only take one hung plate.** Achievable settings are
5, 6.25, 7.5, 10, 11.25, 12.5, 15, 16.25, 17.5, 20, 21.25, 22.5, 25…
Values like 8.75 and 13.75 are **not** possible.

## Pulley ratio

All cable stations in this gym are 2:1 — the load at the handle is half the
stack setting. This doesn't affect programming (ratios cancel when comparing
yourself to yourself), but it matters when sanity-checking a number against a
dumbbell equivalent.

## Notes

- Dumbbells above 10kg are not available in the cable room; anything heavier
  has to happen in the DB section.
- The preacher room has no bench, so spider curls are done face-down on an
  incline bench in the DB section instead.
